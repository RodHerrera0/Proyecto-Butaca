# Butaca

Aplicación web que detecta el ánimo del usuario con la cámara y le recomienda películas y series acordes a cómo se siente.

## Stack

_Por completar: React + Vite, Node + Express, Prisma + Supabase (PostgreSQL), node:test + supertest, Vitest, Playwright y GitHub Actions._

## Estructura del repo

_Por completar: descripción de `frontend/`, `backend/`, `e2e/`, `docs/` y `.github/`._

## Cómo correr el proyecto

_Por completar: pasos para levantar el frontend (`cd frontend && npm install && npm run dev`) y el backend (`cd backend && npm install && npm run dev`)._

## Variables de entorno

_Por completar: copiar `backend/.env.example` y `frontend/.env.example` a `.env` y llenar los valores (nunca subir el `.env`)._

## Pruebas

_Por completar: cómo ejecutar `npm test` en cada carpeta y las pruebas E2E con Playwright._

## Flujo de trabajo con Git

- Nadie trabaja directo en `main` ni en `develop`.
- Cada integrante trabaja en su propia rama y abre un Pull Request hacia `develop`.
- Para hacer merge, el PR necesita **1 revisión aprobada** y el **CI en verde**.
- `develop` pasa a `main` solo para las entregas.
